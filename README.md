# RADAR — сборки

Здесь лежат только готовые файлы RADAR. Исходный код хранится в закрытом репозитории.

**Установка:** откройте [последний релиз](../../releases/latest), скачайте `RADAR-Setup.exe` и запустите его.
Права администратора не нужны. Если Windows SmartScreen предупредит о неизвестном издателе, нажмите «Подробнее» → «Выполнить в любом случае».

**Обновления** приложение находит и ставит само: оно проверяет этот репозиторий при запуске и раз в 6 часов.

Релизы публикуются автоматически. Сборка из закрытого репозитория присылает файлы в ветку `incoming`,
а workflow `publish.yml` проверяет контрольную сумму и выпускает релиз.
